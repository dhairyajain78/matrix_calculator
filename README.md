# matrix_calculator
A Python-based Matrix Calculator that performs various matrix operations through a simple command-line interface.

Features
Matrix Addition
Matrix Subtraction
Matrix Multiplication
Matrix Transpose
Determinant Calculation
Matrix Inverse
User-friendly Menu-Driven Interface
Error Handling for Invalid Matrix Operations
Technologies Used
Python
NumPy

How It Works

The program allows users to input matrices of their desired dimensions and select from multiple operations. It validates matrix sizes before performing calculations and displays the results in a readable format.
